The Trajectonomics design system supplies the tokens, Themes and components that Trajectonomics
interfaces use. It has **no published release yet**, so this section is an outline; there are no
install commands or API examples to follow.

## What it will cover

- **Primitive Tokens and Semantic Tokens**: the raw values and the closed, versioned set of names
  every Theme resolves.
- **Themes**: the built-in light and dark Themes, and a deterministic way to define your own.
- **Svelte components**: the component set for Trajectonomics interfaces.

The repository publishes three packages, `@trajectonomics/design-system`,
`@trajectonomics/design-system-theme` and `@trajectonomics/design-system-svelte`, none of which has
a published release yet. This page will document installation and the Web Consumer Contract when
the first one ships.

Source: [`trajectonomics/design-system`](https://github.com/trajectonomics/design-system).
