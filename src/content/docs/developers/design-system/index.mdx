The Trajectonomics design system will supply the tokens, Themes and components that Trajectonomics
interfaces use. It has **no published release yet**, so this page only records that status; there
are no install commands or API examples to follow.

The design system lives in
[`trajectonomics/design-system`](https://github.com/trajectonomics/design-system). When its first
package ships, this page will document installation, the tokens and Themes, and the components.
