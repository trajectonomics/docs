---
title: help
description: Show usage for traj or for one command.
---

`traj help` shows usage for `traj` or for one command, generated from the same definitions that
validate input
([ADR 0015](https://github.com/trajectonomics/cli/blob/v0.1.0/docs/adr/0015-command-tree.md)).

```bash
traj help         # List the commands.
traj help schema  # Show how `schema` is used.
```

See [Commands](/docs/cli/commands/) for the global options, exit codes and error envelope.
