---
title: version
description: Print the CLI version.
---

`traj version` prints the CLI version. One version binds the tag, the npm package and what the
binary reports
([ADR 0023](https://github.com/trajectonomics/cli/blob/v0.1.0/docs/adr/0023-release-artifacts.md)).

```bash
traj version  # Print the version.
```

See [Commands](/docs/cli/commands/) for the global options, exit codes and error envelope.
