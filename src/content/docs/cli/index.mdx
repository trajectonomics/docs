The Trajectonomics CLI is the command-line interface Operators install and run.

> **Not released yet.** `trajectonomics/cli` has no published release and no install channel. This
> Tab describes the shape of its documentation; it does not yet describe a version you can install.

## In this Tab

- [Installation](/docs/cli/installation/): how to install the CLI once the first release ships.
- [Configuration](/docs/cli/configuration/): how the CLI is configured.
- [Commands](/docs/cli/commands/): the command reference.

Source code and design decisions live in
[`trajectonomics/cli`](https://github.com/trajectonomics/cli).
