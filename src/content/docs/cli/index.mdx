The Trajectonomics CLI, `traj`, is the command-line interface Operators install and run. The latest
release is `v0.1.0`. It keeps a double-entry ledger in one local database and answers balance,
net-worth and report questions about it. It never reads a clock: every command takes its date from
you ([ADR 0018](https://github.com/trajectonomics/cli/blob/v0.1.0/docs/adr/0018-no-clock-in-ledger-commands.md),
[ADR 0029](https://github.com/trajectonomics/cli/blob/v0.1.0/docs/adr/0029-reads-take-their-date-from-the-caller.md)).

## Install

[Installation](/docs/cli/installation/) lists the three install channels. On Linux or macOS, one
line:

```bash
curl -fsSL https://github.com/trajectonomics/cli/releases/latest/download/install.sh | sh
```

## Quickstart

From an empty machine to a first balance:

```bash
traj init                                                      # create ~/.traj and an empty database
traj account add Cash --type asset --currency THB              # an asset account
traj account add Food --type expense --currency THB            # an expense account
traj tx add --from Cash --to Food --amount 120.50 --date 2026-03-01
traj balance --as-of 2026-03-31                                # every account's balance and net worth
```

`--type` and `--currency` are required when adding an account, and THB is the only currency `v0.1.0`
supports. `--as-of` is required on `balance`. Dates are `YYYY-MM-DD`.
